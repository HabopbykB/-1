# Лабораторная работа 1 — вариант `dataset_var2`

Готовый проект под PyCharm по лабораторной работе **«Библиотеки Python для машинного обучения. Работа с данными»**.

## Что адаптировано под ваш датасет

Исходный файл: `data/dataset_var2.csv` (500 строк, 7 столбцов).

Для основного массива варианта используются столбцы:

```python
VARIANT_COLUMNS = ["x1", "x2", "y"]
```

Это соответствует примеру извлечения столбцов в предоставленной методичке и одновременно позволяет отработать реальные проблемы именно этого датасета:

- `x1` содержит 2 текстовых значения `ошибка`, из-за чего исходный тип столбца — `object`;
- `x2` содержит 10 пропусков (`NaN`);
- `y` является корректным числовым столбцом.

Служебные `id`, `timestamp`, `category` и столбец `x3` из исходного CSV не удаляются и не меняются; для лабораторных вычислений создаётся отдельная копия нужных столбцов.

## Запуск в PyCharm

1. Откройте **папку `lab1_variant2`** как проект.
2. Выберите ваш Python Interpreter, где уже установлены библиотеки.
3. Запустите `main.py`.
4. Все таблицы, графики, NumPy-массивы и отчёты появятся в `output/` с датой и временем в имени.

Обычный запуск не требует ввода с клавиатуры и проходит работу целиком. Для демонстрации преподавателю именно интерактивного меню задания 8 можно в Run Configuration добавить параметр:

```text
--interactive-cleaning
```

Для короткой отладочной печати вместо всех 500 строк можно использовать:

```text
--brief
```

## Автоматическая очистка при обычном запуске

Чтобы лабораторная выполнялась целиком без остановки на `input()`, обычный режим применяет к выбранным числовым столбцам тот же сценарий, который доступен через меню:

1. `pd.to_numeric(..., errors="coerce")` — некорректный текст становится `NaN`;
2. пропуски заполняются средним значением соответствующего столбца;
3. итоговый тип `x1`, `x2`, `y` — `float64`.

Исходный `data/dataset_var2.csv` не изменяется.

## Важные детали реализации

- `seed=42` фиксируется для Python/NumPy/TensorFlow/PyTorch.
- Реализовано чтение и запись `.xlsx`, `.csv`, `.txt`, `.mat`; заголовки сохраняются.
- Собственные MinMax `[0,1]`, MinMax `[-1,1]` и z-score хранят параметры и имеют `inverse_transform`.
- Результаты собственного масштабирования сравниваются со `sklearn` через `np.allclose`.
- Тензор `F` содержит **исходные значения, 3 варианта представления масштаба и 4 бинарные маски**, то есть полностью учитывает формулировку задания 48.
- Для задания 49 перебираются несколько наборов признаков из `F` и `MinMaxScaler`/`StandardScaler`; лучший вариант выбирается по validation log-likelihood, дополнительно сохраняются 2D PCA-проекция и график log-likelihood от числа компонент.
- В задании 50 используется включённое в проект цветное изображение `sample_image.png`; операции выполняются NumPy/SciPy/sklearn.
- Если в локальном интерпретаторе отсутствует TensorFlow/Keras или PyTorch, программа напечатает предупреждение и продолжит остальные задания. При установленном полном наборе библиотек выполняются и задания 38-45.
